# awesome-vibecading

A catalog of AI tools for creative software, sorted by program and by task. Competitors included

Part of [VibeCADing](https://vibecading.io), an open innovation lab for AI-native tools in architecture, 3D, games and creative work

## What gets listed

- Open source tools with a commit since April 2026
- 3D generation models are listed by release, without the activity rule
- Star counts as of 24 October 2026

## By program

### Rhino and Grasshopper

- [rhinomcp](https://github.com/jingcheng-chen/rhinomcp) (1.2k stars): Connects Rhino to AI agents through MCP
- [RhinoAI](https://github.com/mcneel/RhinoAI) (377 stars): Official AI integration for Rhino from McNeel, with documentation
- [cordyceps](https://github.com/brookstalley/cordyceps) (107 stars): MCP server for Grasshopper: add and wire components, set values, bake, render
- [rhino-mcp](https://github.com/tanishqbhattad/rhino-mcp) (32 stars): Rhino 8 MCP server aimed at architectural modelling

### Revit

- [aec-model-bridge](https://github.com/Sam-AEC/aec-model-bridge) (74 stars): Revit MCP server and add-in; write tools stay blocked until you approve a plan

## By task

### Text to CAD

- [text-to-cad](https://github.com/earthtojake/text-to-cad) (22.7k stars): Agent plugin that exports STEP, GLB, STL or 3MF, checks manufacturability and makes drawings
- [CADAM](https://github.com/Adam-CAD/CADAM) (5.3k stars): Open source text-to-CAD web app
- [modeling-app](https://github.com/KittyCAD/modeling-app) (1.3k stars): Zoo Design Studio, a CAD app with text-to-CAD built in
- [Multi-Agent-CAD](https://github.com/Pan-Chera/Multi-Agent-CAD) (1k stars): Multi-agent generation of editable parts and assemblies

### Code CAD and BIM libraries agents write

- [openscad](https://github.com/openscad/openscad) (10.5k stars): Script-based solid modeller
- [cadquery](https://github.com/CadQuery/cadquery) (6k stars): Python parametric CAD scripting on OpenCascade
- [build123d](https://github.com/gumyr/build123d) (3.5k stars): Python CAD library on OpenCascade
- [IfcOpenShell](https://github.com/IfcOpenShell/IfcOpenShell) (2.9k stars): IFC library and geometry engine; also home of the Bonsai BIM add-on for Blender
- [archlang](https://github.com/ChanMeng666/archlang) (92 stars): Plain-text floor plans that agents write, compiled to dimensioned SVG, DXF and PDF with checks the agent can read, plus a 3D GLB preview from the same file
- [cadquery-llm-skill](https://github.com/jmwright/cadquery-llm-skill) (11 stars): Skill that teaches LLMs CadQuery and BRep modelling

### Image and text to 3D models

- [Hunyuan3D-2](https://github.com/Tencent-Hunyuan/Hunyuan3D-2) (15.2k stars): High-resolution 3D asset generation
- [TRELLIS](https://github.com/microsoft/TRELLIS) (14.1k stars): Structured 3D latents for generating 3D assets
- [TripoSR](https://github.com/VAST-AI-Research/TripoSR) (7.2k stars): Fast 3D reconstruction from a single image

### Fabrication

- [bambu-printer-mcp](https://github.com/DMontgomery40/bambu-printer-mcp) (230 stars): MCP server for Bambu Lab printers: STL edits, slicing, printing
